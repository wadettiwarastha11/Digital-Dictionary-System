# Digital-Dictionary-System
The program implements a dictionary that stores words and their meanings using a hash table with separate chaining for collision resolution. It supports adding, searching, deleting, and displaying words.

# Dictionary Application Using Hash Tables

## Description
This project implements a dictionary application using
the Hash Table data structure in Python. It stores words
and their meanings and allows users to add, search, update,
delete, and display dictionary entries.

A hash function calculates the index for each word.
When two words map to the same index, collisions are
handled using separate chaining with lists.

## Objectives
- Understand the working of hash tables.
- Implement a hash function in Python.
- Handle collisions using separate chaining.
- Perform insertion, searching, and deletion.
- Develop a menu-driven dictionary application.

## Features
- Add new words and meanings.
- Search for word meanings.
- Update existing meanings.
- Delete dictionary entries.
- Display all stored words.
- Resolve hash collisions using separate chaining.

## Technologies Used
- Programming Language: Python
- Data Structure: Hash Table
- Collision Resolution: Separate Chaining

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

   python dictionary.py

5. Select an option from the menu.

## Applications

## Conclusion
This project demonstrates the practical use of hash

explains hashing and collision resolution using
